# Urban Muslima’h — Urban Abaya Hub™
> Premium AI-Powered Modest Luxury E-Commerce Platform

Urban Muslima’h (Urban Abaya Hub™) is an authentic modest fashion brand founded in 2019 in Agra, Uttar Pradesh, India. This web application provides a high-converting, luxury digital shopping experience matching the brand's Instagram presence ([@urbanmuslimah.co](https://www.instagram.com/urbanmuslimah.co/)).

---

## 🌟 Key Features

1. **Editorial Luxury Design System**
   - Palette: Warm Ivory (`#FAF7F2`), Sand (`#E8DFD3`), Muted Taupe (`#6F645B`), Deep Charcoal (`#161311`), and Champagne Gold (`#CFA86F`).
   - Typography: Cormorant Garamond, Playfair Display, and Plus Jakarta Sans.
   - Glassmorphism overlays, subtle fabric grain textures, smooth slide-in drawers, and refined micro-interactions.

2. **Authentic Product Catalogue (75+ Products)**
   - Signature Scooty Abaya Husna (with 4-way functional zip, double georgette, and rider-friendly drape).
   - Premium Closed & Open Abayas (Nida, Zoom, Georgette fabrics).
   - Daily Wear & Festive Co-Ord Sets.
   - Premium Georgette, Modal, & Silk-Finish Hijabs (from ₹199).
   - Authentic Indian Rupee (`₹`) pricing and real variant selections.

3. **AI Style Assistant (Capsule Wardrobe Wizard)**
   - 4-step interactive styling wizard matching Occasion (Scooty/Commute, Daily Errands, Work/College, Festive/Nikah), Aesthetic, Color Palette, and Budget.
   - Generates curated 2–3 piece wardrobe capsules with 1-click bundle adding and WhatsApp styling consultation.

4. **Natural Language Search**
   - Live query parsing for terms like "everyday hijab under ₹300", "scooty abaya", or "nida fabric".

5. **Scooty Abaya Interactive Size Guide**
   - Accurate measurements: 57" Length, 50" Chest, 53" Waist, 21" Shoulder with free-size fit notes.

6. **Persistent Cart & Honest WhatsApp Checkout**
   - LocalStorage cart persistence with quantity adjusters.
   - Coupon Engine: `FIRST10` (10% off), `SISTERHOOD` (₹150 off), `BARAKAH` (₹200 off above ₹2,500).
   - Delivery details form (Full Name, Phone, Address, Pincode, City, Delivery Notes).
   - Transparent pre-filled WhatsApp checkout URL (`wa.me/918218806608`) with exact order summary, shipping terms, and honest "Confirmation Pending" status.

7. **Sisterhood Proof & Store Locator**
   - Shoppable Instagram grid featuring community reels and photos.
   - Verified customer reviews from Agra, Hyderabad, Srinagar, Mumbai, and Delhi.
   - Physical store details: `17/126, First Floor, near Jay Shiv Plaza, Seo Ka Bazar / Sindhi Bazar, Kinari Bazar Road, Agra, UP - 282003`.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```

---

## 📦 Tech Stack
- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **Icons**: Lucide React + Custom SVG Icons
- **Storefront**: Context API + LocalStorage persistence
